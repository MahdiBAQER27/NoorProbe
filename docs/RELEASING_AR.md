# نشر إصدار جديد

1. عدّل المصدر داخل `src/` ووثّق التغيير في `CHANGELOG.md`.
2. حدّث رقم التطبيق المعروض إلى `2.0.0-beta.3` في `src/App/main.js` وواجهة التعريف، واستخدم رقم Bundle رقمي أعلى من 202 كما توصي Apple.
3. ابنِ الحزمة على macOS من وصف البناء الذي تستخدمه النسخة الحالية. لا تستخدم `src/legacy-swift/`؛ إنه قديم.
4. افتح التطبيق وتحقق من الإقلاع والفحص والتحديث على جهاز مناسب.
5. أنشئ GitHub Release بالوسم `v2.0.0-beta.3` وارفع ملف ZIP اسمه يتضمن NoorProbe، وداخله Noor Probe.app المطابق للوسم.
6. تأكد أن GitHub يعرض SHA-256 digest لأصل ZIP؛ التطبيق يوقف التثبيت إذا لم توجد البصمة أو لم تطابق.
7. جرّب مسار التحديث من نسخة أقدم قبل إعلان الإصدار.

الترتيب: Beta 1 ثم Beta 2 ثم Beta 3، وبعد اعتماد النسخة أزل لاحقة beta. لا ترفع ملفات EFI أو تقارير المستخدم أو مفاتيح الخدمات.
