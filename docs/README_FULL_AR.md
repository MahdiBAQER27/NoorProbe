# Noor Probe 2 Beta 1 — الفحص، EFI، والتنزيل والتحديث

حزمة App تجريبية لmacOS 13+ بواجهة JXA/AppKit/WebKit ومحرك Python 3.9+. لا تحتاج بناء Swift. لم تُشغّل الحزمة أو وظائف macOS على جهاز ماك في بيئة التسليم. ليست نسخة مثبتة التوافق أو أداة إصلاح تلقائي شامل.

## التشغيل

1. فك ZIP على الماك وافتح Noor Probe.app. يمكن نقله إلى Applications.
2. ثبّت Python 3.9+ من https://www.python.org/downloads/macos/ إن لم يكن موجوداً. نسخة /usr/bin/python3 قد تطلب أدوات Apple إذا كانت مجرد stub؛ يفضّل Python المستقل.
3. التطبيق غير موقّع بشهادة Apple وغير notarized. إذا منعه النظام راجع Privacy & Security > Open Anyway بعد التحقق من المصدر، دون تعطيل Gatekeeper.
4. ابدأ الفحص أو اكتشاف EFI. جميع إجراءات التنزيل والتركيب والتعديل منفصلة وتتطلب نقرة وتأكيداً واضحاً.

## التحديث من GitHub

افتح «تحديث التطبيق» وأدخل `owner/repo` أو رابط GitHub مرة واحدة. يجب أن يحتوي الإصدار على وسم مثل `v2.0.0-beta.1` وملف ZIP واحد يتضمن NoorProbe في اسمه، وداخله Noor Probe.app بنفس `NoorUpdateVersion`. النسخة التالية تكون `v2.0.0-beta.2` مع رقم build أعلى. يلزم وجود SHA-256 في بيانات أصل GitHub؛ يرفض التطبيق تثبيت ملف بلا بصمة أو إذا اختلفت. أكّد التنزيل والتثبيت داخل التطبيق. تُحفظ نسخة من الإصدار السابق تحت `~/Library/Application Support/NoorProbe/Updates/Backups`.

## ما معنى الفحص المتعمق؟

- الوجود: ظهرت القطعة في PCI أو USB داخل IORegistry.
- التعرف: توجد واجهة تحت شجرة القطعة، أو خدمات مرشحة للمراجعة. نوقف البحث عند قطعة ناقل فرعية جديدة حتى لا ننسب واجهة ابن إلى جسر PCI الأب.
- التعريف: تعرض أسماء الخدمات ومعرفات الحزم المرشحة، وتُقارن معرفات الحزم بناتج kmutil إن توفر. وجود خدمة تحت الشجرة لا يثبت وحده ارتباط تعريف وظيفي بالقطعة.
- الاستخدام: لواجهات الشبكة نعرض link active/inactive، وجود IPv4، حالة راديو Wi-Fi إذا أمكن، وهل هي المسار الافتراضي IPv4. لا نرسل حزم اختبار إنترنت ولا نعرض IP أو MAC الخام في هذه الخلاصة.
- العمل الحقيقي: لم يتم اختباره تلقائياً. رابط نشط أو IP لا يثبت الإنترنت. واجهة ليست المسار الافتراضي قد تكون مستخدمة لأجهزة محلية أو VPN أو مسارات أخرى. itlwm قد يظهر كEthernet.

لا يمكن لأي فحص من داخل macOS وحده ضمان رؤية جهاز أخفاه BIOS أو ACPI. لا توجد قاعدة توافق PCI/USB شاملة. الصوت والشاشة والسكون واللمس تحتاج اختبارات وظيفية يدوية. الفحص لا يحول بصمة PC إلى Touch ID ولا يصلح NVIDIA غير المدعوم بتعريف وهمي.

## إظهار EFI

- يقرأ diskutil list/info بصيغة plist ويعرض أقسام EFI، دون تركيب أثناء الاكتشاف.
- زر الإظهار يستدعي diskutil mount readOnly لقسم EFI محدد ومتحقق من نوعه.
- إذا احتاج النظام مسؤولاً يوجد زر مستقل يطلب تأكيداً ثم يمرّر أمر diskutil المحدود إلى نافذة صلاحيات macOS. لا يخزّن كلمة المرور.
- إذا كان القسم مركباً مسبقاً لا نعيد تركيبه أو نفصله؛ تُعرض حالته الفعلية وقد يكون read-write.
- يبحث عن EFI/OC/config.plist وOC/config.plist في القسم المركب. تستطيع اختيار أحدهما كمصدر لمساحة العمل.
- لا يجزم أن هذا مصدر الإقلاع الحالي. أقراص FAT العادية التي تضم OpenCore قد لا تكون مصنفة GPT EFI؛ استخدم اختيار مجلد للمصادر الأخرى.
- لا يوجد فورمات أو تفليش أو كتابة تلقائية على قسم الإقلاع.

## تنزيل ملفات GitHub وتطبيقها

1. افتح التنزيل والتطبيق. اختر مشروعاً معروفاً أو أدخل owner/repo عاماً.
2. اضغط جلب الإصدارات. يعرض أول 15 release منشوراً مع الملاحظات ووسم prerelease والأصول.
3. اختر ZIP المناسب لنظامك؛ لا يختاره البرنامج تلقائياً. الحد 200 MiB للملف، و512 MiB لفك الضغط.
4. أكّد التنزيل فقط. يحفظ في ~/Library/Application Support/NoorProbe/Downloads ويفحص الحجم وSHA-256. إذا GitHub وفّر digest تُراجع المطابقة؛ بدونه البصمة محلية وليست تحقق مصدر مستقلاً.
5. يرفض ZIP بمسارات تتجاوز المجلد أو روابط رمزية أو أحجام/أعداد ملفات كبيرة. لا يشغّل ملفات التنزيل.
6. تظهر حزم kext وملفات aml/efi المتاحة للاستيراد. اختر ملفاً واحداً ثم أكّد تطبيقه على Candidate. خيار الاستبدال منفصل. يحتاج Workspace موجودة.
7. راجع التغييرات، شغّل ocvalidate المطابق، واختبر نسخة USB قبل أي اعتماد يدوي.

إضافة كرت/تعريف لا تعني أنه متوافق. تنزيل إصدار OpenCore لا يرحّل config أو يحدّث OpenCore.efi تلقائياً. تنزيل HeliPort لا يثبّت التطبيق أو يشغّله تلقائياً. لا ننزّل Source archives العامة؛ نعرض Release assets فقط، ولا ندعم أرشيفات غير ZIP في الواجهة الحالية. لا توجد مفاتيح API مطلوبة، وقد يظهر حد GitHub rate limit أو خطأ اتصال.

## مساحة العمل والتعديل

تُنسخ EFI إلى Backup وCandidate ويُتحقق من SHA-256. الاستيراد ينسخ الملفات ويسجل المراجع؛ الإضافات المباشرة في Contents/PlugIns تسجل أيضاً، ويرتب اعتمادات الحزم المتاحة. التفعيل والتعطيل يعدّل Enabled. محرر XML يحلل plist قبل الحفظ؛ صحة XML لا تثبت صحة OpenCore. alcid يحتاج قيمة تعرف أنها تناسب Codec، ولا يختارها البرنامج بالتخمين.

قبل كل تعديل توجد نقطة استعادة كاملة من Candidate. عند خطأ يعالجه المحرك ترجع النسخة السابقة. انقطاع الطاقة أو قتل العملية قسرياً ليس مضمون الاسترجاع التلقائي؛ Backup ونقاط History تبقى وسائل استعادة. يوجد قفل يمنع تعديلين متزامنين؛ لا تحذفه أثناء عملية تعمل.

التغييرات لا تُكتب على المصدر. معاينة التغييرات تقارن بصمات الملفات وليست diff لكل سطر. ocvalidate أداة خارجية تختارها وتؤكد تشغيلها؛ تُقارن نسختها بما تدخله، ولا يُكشف إصدار OpenCore تلقائياً. نجاحها ليس ضمان إقلاع.

## الخصوصية والسجلات

التقرير لا يُرفع تلقائياً. GitHub يتلقى طلبات المشاريع والملفات التي تختارها. تُحذف مفاتيح هوية معروفة من تقرير النظام لكن الإخفاء غير شامل؛ راجع التقرير قبل مشاركته. محرر config محلي وقد يحتوي serial/MLB/ROM فلا تشاركه دون إخفائها.

سجل بدء التشغيل: ~/Library/Logs/NoorProbe/launcher.log. عند فشل الفتح أرسل آخر الخطأ، أو شغّل المشغّل من Terminal:

```bash
bash "/path/to/Noor Probe.app/Contents/MacOS/NoorProbe"
```

## الاختبار والقيود

43 اختبار Python ناجح على Linux، مع اختبارات منطق واجهة لتسعة أقسام وsyntax لJXA. اختبارات التنزيل تستخدم fixtures ومصادر وهمية محلياً؛ لم يُختبر تنزيل حقيقي أو macOS diskutil/networksetup/ioreg أو نافذة صلاحيات أو الجسر الأصلي أو فتح الحزمة. الصورة السابقة مولدة للتصميم وليست لقطة تشغيل.

ملفا App/main.js وApp/ui.html وملفات engine مصدر النسخة الحالية. واجهة Swift في Sources وbuild.command قديمان ولا يشملان إضافات 1.2؛ لا تستبدل الحزمة الحالية ببنائهما.

تاريخ الإصدار: 17 نوفمبر 2026. أكواد إضافية: EFI-200…204 للاكتشاف والتركيب؛ GH-001…009 للمصدر والتنزيل والفك والتطبيق. أخطاء نظام أو GitHub غير المتوقعة قد تظهر برسالتها الأصلية.

## إضافات 1.3

- المظهر النهاري والليلي وخيار اتباع النظام بتصميم زجاجي مستوحى من macOS 27. واجهة التطبيق AppKit/WebKit وتستهدف macOS 13 فما فوق.
- لمقارنة PCI، شغّل `lspci -Dn > pci.txt` من Linux على الجهاز نفسه، ثم افحص macOS واستورد pci.txt من الفحص المتعمّق. المطابقة بالمعرّف والعدد. لا تشمل قطعاً حجبها firmware عن النظامين. المقارنة تبقى في الجلسة ويصفّرها بدء تقرير جديد.
- مساعد AI فيه خمس خانات: Google AI Studio وGroq وOpenRouter وCloudflare Workers AI وHugging Face. اختَر مزوداً واحداً أو الكل لإجابات مستقلة بالتوازي. أدخل المفاتيح في نافذة التطبيق. تبقى في ذاكرة الجلسة، وCloudflare يحتاج Account ID.
- للاستخدام المجاني اختَر حساباً بلا فوترة أو ترقية ونموذجاً متاحاً ضمن حصته المجانية. OpenRouter محصور في openrouter/free أو :free. التطبيق لا يقرأ خطة حسابك أو رصيد المزوّد ولا يضمن تكلفة حساب مربوط بالدفع.
- خيار إرفاق الفحص يرسل ملخصاً محدوداً للتعريفات ومعرّفات PCI وUSB وحالة الشبكة وأكواد الفحص ونتيجة المقارنة. ملفات EFI الخام خارج هذا الملخص. المساعد يشرح ويقترح، وعمليات التعديل تتم من واجهة مساحة EFI.
- اختبارات 1.3 محلية على Linux. تشغيل الحزمة على macOS والاتصال الحقيقي بالمزوّدين باستخدام مفاتيح المستخدم ينتظر تجربة فعلية.
