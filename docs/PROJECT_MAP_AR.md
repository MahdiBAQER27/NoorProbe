# خريطة المشروع — عدّل من أين؟

| تريد تغيير | الملف أو المجلد |
|---|---|
| شكل الواجهة وأقسامها | `src/App/ui.html` |
| ربط أزرار الواجهة بـ macOS والمحرك | `src/App/main.js` |
| فحص الجهاز وتقارير النظام | `src/engine/probe.py` |
| عمليات EFI والتنزيل والتحديث | `src/engine/advanced.py` |
| مزودي المساعد الذكي | `src/engine/assistant_ai.py` |
| اختبارات المنطق | `tests/` |
| إرشادات التشغيل والأدوات | `docs/` |
| نسخة Beta 3 الحالية | `dist/NoorProbe-2.0.0-beta.3/` وملفها المضغوط |
| واجهة Swift قديمة للمراجعة فقط | `src/legacy-swift/NoorProbe.swift` |

ملفات التطبيق الجاهز محفوظة في مجلد التسليم خارج المستودع. المصدر النشط موزع تحت `src/`؛ لا تعدّل واجهة Swift القديمة ظناً أنها تنشئ نسخة التطبيق الحالية. راجع دليل البناء قبل إنشاء إصدار جديد.
