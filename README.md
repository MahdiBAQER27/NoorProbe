# Noor Probe

أداة فحص Hackintosh ومراجعة EFI على macOS. المشروع ما زال تجريبياً.

- دليل الاستخدام بالعربي: docs/README_FULL_AR.md
- خريطة المشروع: docs/PROJECT_MAP_AR.md
- سجل التغييرات: CHANGELOG.md
- أحدث المصدر: 2.0.0 Beta 3.

يتطلب macOS 13+ وPython 3.9+ للفحص. مساعد AI اختياري؛ الفحص ومراجعة نطاق Kernel يعملان محلياً. لا يكتب التطبيق تلقائياً على EFI الأصلية.
