# Noor Probe

أداة عامة ومفتوحة المصدر لفحص Hackintosh ومراجعة ملفات EFI على macOS.

## آخر إصدار

**2.0.0 Beta 3** — [تنزيل Noor Probe مباشرة من GitHub Releases](https://github.com/MahdiBAQER27/NoorProbe/releases/latest). يمكن للتطبيق أيضاً فحص التحديث وتنزيله من زر التحديث داخله.

## ما الذي يقدمه؟

- تقرير معلومات النظام ومكونات Hackintosh.
- مراجعة EFI وملفات Kext وإظهار حدود Kernel المسجلة في config.plist.
- مؤشر نطاق Kernel يساعد على معرفة ما إذا كان OpenCore سيُدرج التعريف بحسب الإصدار؛ لا يؤكد وحده أن التعريف مناسب للجهاز.
- تركيب EFI للعرض في Finder مع نسخ احتياطية عند تعديل مساحة عمل منفصلة.
- مساعد AI اختياري؛ لا يحتاج الفحص الأساسي إلى AI أو مفتاح API، وتبقى القراءة والتحليلات المعتادة محلية.
- تحديث داخل التطبيق من إصدارات هذا المستودع العام، مع التحقق من SHA-256 قبل التثبيت.

## متطلبات التشغيل

- macOS 13 أو أحدث.
- Python 3.9 أو أحدث للفحص.

هذا مشروع تجريبي. نتائج الفحص مؤشرات مساعدة وليست ضماناً لتوافق EFI مع جهاز بعينه. احتفظ بنسخة احتياطية ولا تثبّت EFI قبل مراجعة الإعدادات.
